🔍 How to Debug Font Matching & Fallbacks
Google Fonts query:

1. Chrome DevTools "Rendered Fonts" (The definitive test): Right-click the headline text → Inspect. In the right panel, select the Computed tab and scroll to the very bottom to Rendered Fonts. Chrome will display the exact font file used (e.g. Comic Sans MS vs Roboto) and how many glyphs it rendered.

2. Why Headlines might fall back: The headlines use font-weight: 100 (Thin) while paragraphs use font-weight: 400. If the loaded web font or system font does not provide a 100 face, or if specific diacritics / Cyrillic characters are missing from the thin cut, the browser performs per-character font fallback to the next font in the stack that supports them.

3. JavaScript Console check: Run document.fonts.check('100 24px Roboto') vs document.fonts.check('400 24px Roboto') in DevTools Console.
